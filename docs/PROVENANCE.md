# What was supplied, and what this continuation can prove

Prepared on 11 November 2026 for Lin Htet Aung.

The original ZIP files remain unchanged in the parent directory. This working project
combines Saniah's Stages 1/3, Javed's Stage 2, and Nyo's Stage 4. Conflicting files are
retained under `submissions/`; the three results dictionaries are merged by key, never
by replacing a whole dictionary. Stage 2 event/matching files are byte-identical across
the two submissions that contain them.

The supplied folder had no Git history. A local checkpoint before this continuation's
real-effect calculations records the inherited decisions and simulation evidence.
It cannot establish that the original team committed decisions before original scoring,
or that nobody previously inspected effects. Saniah's archive already contained
event-effect files. No historical dates or approvals are invented.

Raw household CSVs and the earlier EDA scripts were not supplied. The matrices were
supplied. A prepared-input reproduction therefore starts from those matrices; it is
not evidence of a fresh download-to-results reproduction. The raw-data mode is supplied
for the team to complete that stronger check once the actual CSVs are available.

Nyo's inherited simulation validates the High-event procedure under its specified
model. It does not validate random assignment, remove selection bias, or model all
dependencies between calendar days reused across events. The additional real-score
resampling coverage exercise is conditional on the observed household distributions;
it is not independent proof of population coverage.

No work has been pushed to GitHub or sent to teammates. Repository review, merging,
live presentation rehearsals and the full raw-data reproduction remain team actions.
