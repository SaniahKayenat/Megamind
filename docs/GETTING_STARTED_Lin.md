# Lin's handoff package

Start with reports/START_HERE.md. The repository includes local Git history because the
results gate checks a pre-analysis checkpoint. Keep the hidden .git folder when extracting.
No remote is configured in this portable copy.

Large matrices, raw data and the Python environment are intentionally excluded. To rerun,
place H2013.npy from Saniah's original submission under data/interim/ and Tariffs.xlsx from
Javed's submission under data/raw/, then follow README.md to install the pinned packages.

The prepared-input analysis reproduced exactly in a clean environment. Original raw
household CSVs are still needed for a complete raw-download verification. The editable
slides accompany the Codex handoff separately; see reports/PRESENTATION.md and
reports/SPEAKER_NOTES.md. Code, tables, figures, report drafts and all explanations are here.
